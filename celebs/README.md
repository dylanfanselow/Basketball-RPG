# Hand-edited celebrity art

`celeb_NN.png` (NN = 00–15) replaces the generated sprite sheet of courtside celeb NN. Each file is 192×120:
four 48×120 frames side by side — seated, cheering (standing, arms up), filming with a phone, hands to face.

Made with the in-game pixel editor (dev panel → **Pixel editor**, or open the game with `?editor`). Under
`npm run dev`, **Save to repo** writes the file here; commit and push it. Files are bundled inline, so they also
show up in the single-file browser build.
